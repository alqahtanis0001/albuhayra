## Gotchas I found
- `parseUsedGroups` does not filter unknown keys (only non-strings); `openGroupKeys` now does, pinned.
- With the add entry in the nav, `navItems()` is no longer "every entry" — everything that wants links must go through it (`activeHref`, `groupOf`, tab/more split). `tabEntries()` is the one place that sees both kinds.
- React's static markup puts `aria-current` and `class` before `href`; render assertions must match attributes with `/<a [^>]*href="…"/`, not `'<a href="…"'`.
- A static render of anything that reaches `DueRows` needs `server-only`, `@/lib/db` and `next/cache` mocked (the reminder action is in the import graph even when no row renders).
- No `react-dom/server` precedent existed in `src/**` despite the brief's wording; `nav.test.ts` is now the precedent (`createElement` + `renderToStaticMarkup`, `next/navigation` mocked with a settable pathname via `vi.hoisted`).
