## Things to know
- `Select` supports `groups`, `trailing`, `placeholder` (see `LinkFields`).
- `PlanForm` posts `partyId` through the select's `name` when not locked — keep that; the sentinel must never be the posted value (use a hidden input like `LinkFields`, or filter the value before it reaches the `name`d select).
- `createParty` returns `ActionResult<{ id }>`; `PartyOption` is `{ id, name, type, active }`.
- `t.partyType.*` has the type labels; `t.parties.*` the party words; `t.common.save/cancel`.
